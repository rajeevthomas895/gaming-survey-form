# Gaming Survey Form

A gaming survey form built with HTML and CSS as part of the freeCodeCamp Responsive Web Design Certification.

## Live Demo

[View Live Project](https://rajeevthomas895.github.io/gaming-survey-form/)

## About the Project

This project was completed as part of the freeCodeCamp Responsive Web Design Certification.

freeCodeCamp provided the project requirements and user stories, while I wrote the HTML and CSS implementation and customized the project with a gaming survey theme.

## Features

- Name and email input fields
- Age input with validation
- Gaming platform dropdown
- Radio button selections
- Multiple checkbox selections
- Text area for additional responses
- Submit button

## Built With

- HTML
- CSS
